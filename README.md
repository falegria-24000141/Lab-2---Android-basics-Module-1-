# 📱 Laboratorio 02 - Android Basics

## ⚔️ RPG Character Sheet
Desarrollo de una hoja de personaje con lógica de dados.

**Avances de Desarrollo:**
* **Fase 1:** Configuración de estados (`mutableIntStateOf`) para Vitalidad, Destreza y Sabiduría.
* **Fase 2:** Diseño de interfaz modular con `StatRow` y tarjetas elevadas.
* **Fase 3:** Implementación de lógica aleatoria y validaciones de puntaje (*Godlike* / *Re-roll*).
* **Fase 4:** Control de eventos de usuario y función de reinicio completo.

## 🚦 Traffic Light Simulator
Simulador de semáforo con ciclos de tiempo automáticos.

**Avances de Desarrollo:**
* **Fase 1:** Diseño visual de las luces (`LightCircle`) y contenedor principal.
* **Fase 2:** Definición de estados de color y estructura de control.
* **Fase 3:** Implementación de `LaunchedEffect` y `delay` para el cambio automático de luces.
* **Fase 4:** Optimización de la máquina de estados y limpieza de dependencias.
